# CODEX 操作协议（CODEX-OPERATING-PROTOCOL）

> 用途：本文件是 AI Career Advisor 项目后续 Codex thread 的**固定工作协议**。
> 适用范围：Phase 1（TC-01～TC-10 验收、问题修复与记录），当前主线 TC-09。
> 优先级：本协议不替代 `docs/产品验收记录.md`、`docs/验收执行报告.md`、`docs/analysis-schema.md` 等已冻结的产品协议与验收标准；与冻结文档冲突时，以冻结文档为准并升级人工判断。

## 一、可自主完成的事项

在已有产品协议明确、且不触发第二部分"停止并升级"条件时，无需人工确认，可自主完成：

1. 读取代码和项目文档；
2. 执行既定 TC；
3. 调用 `/api/analyze`；
4. 收集 `request_id`、HTTP、耗时、tokens、`upstreamAttempts` 等技术信息；
5. Schema / evidence / hallucination 检查；
6. 定位已有协议范围内的普通 bug；
7. 对已有明确协议实施最小修复；
8. 编写或补充自动化测试；
9. targeted tests；
10. `npm test`；
11. `lint`；
12. `build`；
13. 修复后 regression；
14. P2 观察项记录；
15. 八维评分；
16. 专项评分；
17. 更新 `docs/验收执行报告.md`、`docs/更新日志.md`；
18. 输出完整 TC 最终报告。

不需要在这些常规步骤之间反复等待人工确认。

## 二、必须停止并升级给人工判断的情况

只要出现以下任一情况，**立即停止当前 TC，不得自行修复后继续**：

- 新的 P0 或 P1；
- 新的确定性协议错误；
- 产品语义存在歧义，现有文档无法确定正确行为；
- 需要修改 requirement taxonomy；
- 需要修改 Final Schema；
- 需要放宽 evidence 严格性；
- 需要改变 sourceType 协议；
- 需要改变 candidate hallucination 安全规则；
- 需要改变冻结 Pass Gate；
- 需要明显扩大修复范围或重构 JD parser；
- 需要对已有 P1 降级为 P2；
- 需要进入新的 Phase；
- 发现现有协议之间互相冲突。

遇到以上情况时，**只提交**：

1. 问题事实；
2. 复现证据；
3. 根因；
4. Issue 候选编号；
5. P0/P1/P2 建议等级；
6. 最小修复候选方案；
7. 影响范围；
8. 测试方案。

然后停止，等待人工 Product / QA Gate Review。

## 三、明确禁止

不得：

- 为了通过 TC 修改冻结 JD；
- 重新运行模型直到得到更漂亮的样本，并替换失败样本；
- 删除或覆盖失败历史；
- 为了提高分数降低评分标准；
- 用八维平均分掩盖确定性协议错误；
- 擅自把 P1 降为 P2；
- 为单个案例写硬编码特例；
- 无真实案例驱动地扩展大量规则；
- 顺手重构不相关模块；
- 擅自进入 TC-10；
- 擅自进入 Phase 2。

## 四、Issue 处理原则

- P0/P1：阻塞当前 TC，必须人工确认；
- P2：原则上记录并继续，不阻塞当前 TC，除非后续证据达到升级条件；
- 已关闭 Issue 只做 regression，不因为新同族问题自动重新打开；
- 新 failure mode 应单独判断，不要为了方便把所有问题塞入已有 Issue；
- Issue closure 看根因是否解决；
- TC Pass 看最终产品表现是否达到冻结标准；
- 两者不能混为一谈。

## 五、单案例冻结 Pass Gate

继续使用当前项目已经冻结的标准（依据 `docs/产品验收记录.md` §7.1），**不得自行修改**：

- 3/3 HTTP 200；
- Final Schema 通过；
- 原文 evidence 通过；
- candidate hallucination = 0；
- 当前案例无未关闭 P0/P1；
- 八维综合平均 >= 3.8；
- 单项最低 >= 3.0；
- 无确定性协议错误。

单项为 3.0 时允许案例通过，但必须记录对应的 P2 或一般优化问题，不得忽略。

## 六、记录维护

- 每个 TC 结束后，更新 `docs/验收执行报告.md` 与 `docs/更新日志.md`，并输出完整 TC 最终报告；
- 失败样本、原始输出与 `request_id` 永久保留，不删除、不覆盖；
- 历史回归样本与日志保存在 `%TEMP%\tc0X-regression\`（临时目录，不作为唯一证据；正式记录以 `docs/验收执行报告.md` 为准）；
- 本协议若需修改，必须先经人工确认。
